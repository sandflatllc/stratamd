The [workspace version](02-workspace.md) is the selected direction. Its latest revision uses a more relaxed voice and removes the personal introduction by name.

| Draft | Emphasis |

The root README is unchanged while these alternatives are being considered. The links in these drafts resolve from this directory. When promoting a version to the root, adjust its relative links to match.

The screenshots are real Strata windows with fictional conversations and a local demo website. [Capture details](capture-notes.md).
