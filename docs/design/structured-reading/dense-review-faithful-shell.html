Verdict

Mesa's product is strong and its written process is upside down. The rules that protect Mesa live in the database and launcher scripts. The rules agents keep breaking live in prose.

Four facts carry the whole review. The cards make each claim distinct while keeping its evidence one action away.

01Process miss08 §2.3, §7.5

Not one defect in either major August postmortem was caught by a canon rule. The owner caught more invented facts than any process stage.

02Instruction load01 §2, §7d

An agent following the router's own read chain loads about 43,000 tokens before touching code. The useful rules fit in about 5,000.

03Gate failure03 §0, 04 §1

CI has been red since 2026-06-19 and every push to main deployed anyway. Playwright has never run in CI.

04Rules that hold02 §4, 06 §3

Money and piece-rate rules hold at the database. Core records still have 6 to 47 write paths each with no equivalent guard.
