# Sent comments mockup

Design preview only. Open `mockup.html`; the top link switches between the two actual exchanges in the supplied screenshots. View passage opens the original message block and highlights the selected words.

The default view shows every selected passage and its exact sent response, grouped in one user message. The header counts comments instead of exposing the generated context attachment.

Assets come from `src/renderer/styles.css` and the built Baloo 2 font files in `out/renderer/assets/`. The HTML embeds these assets so it can be opened independently. Sent quotes and responses come from the corresponding saved conversation attachments.

This proposal does not change application code.
